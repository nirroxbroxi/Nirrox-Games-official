ÉVEIL ARTIFICIEL

Robot ouvrier doté d'une conscience humaine et d'une démarche articulée. Évase-toi de l'usine, utilise ton jetpack et ton bouclier réflecteur (touche Shift) pour renvoyer les tirs ennemis sur eux !

COMMANDES SYSTÈME :

  • Q / D ou Flèches G/D : Se déplacer (Animation de marche articulée)
  • Espace / Flèche Haut (Maintenir) : Jetpack progressif
  • Shift Gauche / Touche S : Activer le bouclier réflecteur (durée 1 seconde, renvoie les tirs)
  • Clic Gauche / Touche F : Tir Plasma depuis le bras
  • Code secret : Taper god pour activer l'invincibilité.
